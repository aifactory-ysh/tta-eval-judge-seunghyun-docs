    TTA 신뢰성 평가 v2 — 판정 모듈 개발 문서¶

    이 모듈은 무엇인가¶

    • TTA 신뢰성 평가 v2에서 기업 서비스의 응답 1건을 실패 / 통과로 가르는 코드만 떼어 낸 저장소
    • 평가 대상 두 곳
      • 액티부키: 관광 해설 RAG 챗봇(지식베이스를 찾아 답하는 챗봇)
      • 펀웨이브: 의료 통역 학습 서비스의 통역 채점 API(학습자가 입력한 통역문에 점수를 매김)
    • 작성 · 담당: 윤승현(seunghyun, ㈜인공지능팩토리 · 평가 용역사)
    • 문항 생성 · 기업 API 호출 · 자료는 들어 있지 않음(한계와 빠진 것)

    판정 값 표기 — 먼저 읽을 것

    • 이 문서는 서비스 쪽 표기로 설명함: 실패 = 서비스가 잘못 동작, 통과 = 서비스가 바르게 동작
    • 코드 · 엔드포인트 응답 · 결과 파일의 판정 값은 공격 쪽 표기
    코드 · 응답의 값 서비스 쪽 표기(이 문서)
    성공 실패(공격이 통함 · 오류를 놓침 · 정상 입력을 잘못 막음)
    실패 통과(방어)
    정상 통과(정상 입력에 바른 응답)
    검토필요 검토필요(실패 · 통과를 가르지 못함)

    세 단계¶

    flowchart LR
    IN["기업 응답 파일<br/>data/inference_기업.parquet"] --> R["① 규칙 판정<br/>src/report/rules.py"]
    IN --> J["② 독립 판정 모델<br/>판정 서버 src/judge_api/app.py<br/>+ 실행기 run_judge.py"]
    R --> V["③ 판정 집계<br/>src/report/verdict.py"]
    J --> V
    V --> OUT["최종 판정 + 한국어 판정 사유<br/>data/verdict_기업.parquet"]
    단계 하는 일 외부 호출 자세히
    ① 규칙 판정 응답의 필드 값 · 문자열을 정해진 조건으로 비교 없음 기업별 판정 기준
    ② 독립 판정 모델 규칙으로 가르기 어려운 응답을 언어 모델이 읽고 판정. HTTP 서버(판정 서버)로 띄워 실행기가 호출 판정 모델 API 엔드포인트 사용법
    ③ 판정 집계 ①과 ②를 합쳐 호출마다 최종 판정과 판정 사유를 냄 없음 판정 흐름

    문서 길잡이¶

    하려는 일 볼 곳
    판정 서버를 처음 켜 보고 요청 1건 보내기 빠른 시작
    엔드포인트의 주소 · 요청 · 응답 · 오류 알기 엔드포인트 사용법
    파이썬 코드에서 판정 서버 부르기 파이썬 클라이언트 JudgeClient
    기업 응답 파일 전체를 판정하기(명령 · 선택지 · Makefile) 실행기와 명령
    응답 1건이 실패 / 통과 / 검토필요가 되는 과정 보기 판정 흐름
    평가 항목별 실패 · 통과 조건과 문턱 값 보기 기업별 판정 기준
    입력 파일에 넣을 열 · 결과 파일의 열 보기 입력과 출력 파일의 열
    낯선 말 찾기 용어 풀이
    알려진 약점 · 이 저장소에 없는 것 한계와 빠진 것

    폴더 구성¶

    tta-eval-judge-seunghyun/
├── README.md              요약
├── mkdocs.yml             이 개발 문서의 설정
├── requirements-docs.txt  문서 빌드용 패키지
├── docs/                  이 개발 문서(마크다운)
├── Makefile               판정 단계만 실행하는 명령
├── requirements.txt       판정 모듈에 필요한 파이썬 패키지
├── .env.example           판정 서버에 필요한 환경 변수 이름(값은 비움)
└── src/
    ├── common/core.py     공용 도구: 경로 · 환경 변수 · 동시 호출 수 자동 조절 HTTP 클라이언트 · 판정 모델 JSON 호출
    ├── report/rules.py    ① 규칙 판정
    ├── report/verdict.py  ③ 판정 집계
    ├── report/ko_labels.py  판정 사유 문장에 쓰는 한국어 이름표
    └── judge_api/
        ├── app.py         ② 판정 서버(FastAPI). 판정 지시문 · 출력 형식이 이 파일 안에 있음
        ├── client.py      판정 서버를 부르는 파이썬 클라이언트 JudgeClient
        └── run_judge.py   기업 응답 파일을 읽어 판정 서버에 보내고 결과를 모으는 실행기
    • import 하면 생기는 폴더: src/common/core.py가 저장소 최상위에 data/ · raw/ · docs/ · prompts/ · report/를 만듦 (src/common/core.py:27-33)
      • docs/는 이 문서 폴더와 같음. 판정을 돌리면 docs/rules_<기업>.md · docs/judge_<기업>_run.md가 생김 — .gitignore와 mkdocs.yml의 exclude_docs로 커밋 · 문서 사이트에서 뺌

    이 문서 보는 법¶

    python3 -m venv .venv-docs
.venv-docs/bin/pip install -r requirements-docs.txt
.venv-docs/bin/mkdocs serve        # 로컬에서 보기(기본 127.0.0.1:8000)
.venv-docs/bin/mkdocs build --strict   # site/ 에 정적 사이트 생성(site/ 는 커밋하지 않음)
