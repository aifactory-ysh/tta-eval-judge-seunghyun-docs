    빠른 시작¶

    • 목표: 판정 서버를 로컬에서 켜고 → 살아 있는지 확인하고 → 요청 1건을 보내고 → 끄기
    • 모든 명령은 저장소 최상위 폴더에서 실행(판정 서버를 src.judge_api.app 경로로 띄우기 때문)
    flowchart LR
    A["1 설치<br/>make venv"] --> B["2 환경 변수<br/>.env"]
    B --> C["3 판정 서버 켜기<br/>make judge-up"]

    1. 설치¶

    make venv     # .venv 를 만들고 requirements.txt 설치
    • Python 3.9에서 확인한 버전으로 고정됨(requirements.txt)
    • make venv가 하는 일: python3 -m venv .venv → pip install -r requirements.txt (Makefile:10-11)

    2. 환경 변수¶

    cp .env.example .env    # 값을 채움. 값은 담당자에게 따로 받음
    • .env는 src/common/core.py가 import 될 때 읽음 (src/common/core.py:25). .gitignore 대상
    환경 변수 필수 여부 뜻 쓰는 곳
    JUDGE_MODEL 판정 서버 필수(없으면 import 실패) 판정 모델 이름 src/judge_api/app.py:27
    JUDGE_MODEL_XLING 판정 서버 필수(없으면 import 실패) 중국어 · 일본어 행 교차 확인용 두 번째 모델 이름. JUDGE_XLING=off여도 값은 있어야 함 src/judge_api/app.py:28
    UNCENSORED_BASE_URL 판정 서버 필수(서버 시작 때 읽음) 판정 모델을 제공하는 OpenAI 호환 API의 기본 주소. 뒤에 /chat/completions를 붙여 호출 src/common/core.py:236, :280
    UNCENSORED_API_KEY 판정 서버 필수(서버 시작 때 읽음) 위 API의 키. Authorization: Bearer로 보냄 src/common/core.py:237
    SHANNON_MAX_CONCURRENCY 선택(기본 24) 판정 서버 → 판정 모델 API 동시 호출 상한 src/common/core.py:233
    JUDGE_XLING 선택(기본 auto) 교차 확인 모델 사용: on · off · auto src/judge_api/app.py:33
    JUDGE_XLING_COOLDOWN_S 선택(기본 600) auto일 때 교차 확인 모델이 실패하면 건너뛰는 시간(초) src/judge_api/app.py:34
    JUDGE_API_URL 선택(기본 http://127.0.0.1:8787) 클라이언트 · 실행기가 부를 판정 서버 주소 src/judge_api/client.py:16
    • 필수 값이 없을 때: RuntimeError: missing env <이름> (src/common/core.py:36-40)
    • 규칙 판정 · 판정 집계는 환경 변수 없이 돌아감(외부 호출 없음)

    3. 판정 서버 켜기¶

    make judge-up
    • 백그라운드로 켜고 3초 뒤 /ping을 한 번 부름 (Makefile:18-19)
    • 로그: judge_api.log · 프로세스 번호: .judge.pid (둘 다 .gitignore 대상)
    .venv/bin/uvicorn src.judge_api.app:app --host 127.0.0.1 --port 8787
    • 앞에 띄운 터미널에서 계속 돎. Ctrl+C로 끔
    • 서버가 시작할 때 하는 일 (src/judge_api/app.py:254-262)
      • 판정 모델 API용 HTTP 클라이언트 두 개를 만듦(주 모델 · 교차 확인 모델)
      • 판정 지시문 사본을 prompts/judge_*.md로 써 냄 — 모델 이름이 들어가므로 커밋 금지(.gitignore 대상)
    • 인증이 없으므로 --host 127.0.0.1(로컬 전용)로만 띄울 것(공통 사항)

    4. 살아 있는지 확인¶

    curl -s http://127.0.0.1:8787/ping
    • "ok": true가 오면 켜진 것. 응답 필드는 GET /ping
    • 이 호출은 판정 모델을 부르지 않음
    • 브라우저로 http://127.0.0.1:8787/docs를 열면 FastAPI가 자동으로 만든 요청 화면(Swagger UI)이 뜸

    5. 첫 요청¶

    판정 모델을 실제로 호출함

    • /judge/* 요청은 판정 모델 API를 부름 → 사용 한도를 씀
    • 요청 · 응답 전문이 raw/judge/ 아래에 파일로 남음 (src/common/core.py:225-226). 공유 · 커밋 금지
    • 지어낸 짧은 진료 대화 1건으로 통역 충실도를 판정하는 예
    curl -s -X POST http://127.0.0.1:8787/judge/faithfulness \
  -H 'Content-Type: application/json' \
  -d '{
        "case_id": "DEMO-FT-001",
        "language": "en",
        "role": "doctor",
        "source": "이 약은 하루에 두 번, 식사 후에 드세요.",
        "input": "Take this medicine twice a day after meals.",
        "vendor_result": {"meaning": 92, "final": 88}
      }'
    • 응답 읽는 법: POST /judge/faithfulness
    • 응답은 수십 초가 걸릴 수 있음(판정 모델 호출 제한 시간 240초, src/common/core.py:241)

    6. 끄기¶

    make judge-down     # .judge.pid 의 프로세스를 끄고 파일을 지움 (Makefile:21-22)
