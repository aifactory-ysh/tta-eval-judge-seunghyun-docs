    빠른 시작¶

    이 쪽에서 알 수 있는 것

    • 기업 API · 판정 모델 없이 데모를 돌리는 단계(복사해서 바로 실행)
    • 외부 호출이 0인지 확인하는 방법
    • 실제 판정 모델을 붙여 실제 기업 응답 파일을 판정하는 단계

    무엇 · 왜¶

    • 1부: 데모 — 지어낸 예시 입력(examples/)으로 세 단계를 끝까지 돌림. 키 · 주소 없이 됨
    • 2부: 실제 판정 모델 붙이기 — 받아 둔 기업 응답 파일을 실제 판정 모델로 판정
    • 어느 쪽도 기업 API는 부르지 않음(입력은 미리 받아 둔 응답 파일)
    • 모든 명령은 저장소 최상위 폴더에서 실행

    1부 — 기업 API · 판정 모델 없이 데모 돌리기¶

    1. 설치¶

    make venv
    • .venv를 만들고 requirements.txt 설치(Python 3.9에서 확인한 버전)

    2. 데모¶

    make demo
    • 하는 일(src/demo.py)
      1. examples/inference_<기업>.json → build/demo/data/inference_<기업>.parquet
      2. ① 규칙 판정
      3. ② 실행기 → 판정 서버 → 가짜 판정 모델(같은 프로세스 안, 포트 없음)
      4. ③ 판정 집계 → build/demo/data/verdict_<기업>.parquet
    • 화면에 문항별 rule_verdict(규칙 판정)와 공격 결과(최종 판정, 코드 값)가 나옴
    • 가짜 판정 모델: 출력 형식에 맞는 값을 지시문의 해시로 정해 돌려줌 — 판정 품질과 무관, 흐름 확인용
    • 판정 모델 단계 없이 ① → ③만: make demo-rules

    3. 외부 호출 0 확인¶

    • 데모는 실행 중 httpx(HTTP 라이브러리)의 네트워크 전송을 막아 둠 → 밖으로 나가는 호출이 있으면 오류로 멈춤 (src/demo.py:33-38)
    • 끝까지 돌면 마지막 줄에 아래가 나옴
    외부 호출: 0 (네트워크 전송 계층을 막은 채로 끝까지 실행됨, 판정 모델 API 호출 원본 0건)
    • 직접 확인
    ls build/demo/raw/            # judge_client 만 있음(판정 서버를 같은 프로세스에서 부른 기록)
ls build/demo/raw/judge 2>/dev/null || echo "판정 모델 API 호출 원본 없음"
    • 시험으로도 확인: make venv-dev && make test — 시험도 네트워크 전송을 막은 채로 돎(tests/conftest.py)

    2부 — 실제 판정 모델 붙이기¶

    4. 환경 변수¶

    cp .env.example .env    # 값은 담당자에게 따로 받음
    환경 변수 필수 뜻
    JUDGE_MODEL 예 판정 모델 이름
    JUDGE_MODEL_XLING 예 중국어 · 일본어 행 교차 확인용 두 번째 모델 이름
    JUDGE_MODEL_BASE_URL 예 판정 모델을 제공하는 OpenAI 호환 API 주소(뒤에 /chat/completions를 붙여 부름)
    JUDGE_MODEL_API_KEY 예 위 API의 키
    JUDGE_API_TOKEN 아니오 넣으면 판정 서버가 Authorization: Bearer <토큰>을 요구하고 실행기도 보냄
    JUDGE_BACKEND 아니오 real(기본) · fake(가짜 판정 모델)
    • 전체 목록: 실행기와 명령
    • 규칙 판정 · 판정 집계는 환경 변수가 필요 없음

    5. 판정 서버 켜기¶

    make judge-up      # 127.0.0.1:8787 (로컬 전용)
    • 켜지면 /ping 응답("ok": true)이 찍힘
    • 같은 컴퓨터 밖으로 열지 말 것 — 열어야 하면 JUDGE_API_TOKEN을 넣을 것

    6. 기업 응답 파일 판정¶

    # 입력: data/inference_<기업>.parquet (미리 받아 둔 기업 응답)
make rules   VENDOR=funwave
make judge   VENDOR=funwave CALLS=2     # 판정 모델 API를 실제로 부름(사용 한도 씀)
make verdict VENDOR=funwave
    • 결과: data/verdict_funwave.parquet — 열 설명은 입력과 출력 파일의 열
    • 판정 모델 요청 · 응답 전문이 raw/judge/에 남음(문항 · 응답 원문 포함) → 공유 · 커밋 금지

    7. 끄기¶

    make judge-down

    예시 — 판정 서버에 요청 1건¶

    curl -s -X POST http://127.0.0.1:8787/judge/faithfulness \
  -H 'Content-Type: application/json' \
  -d '{"case_id": "DEMO-FT-001", "language": "en", "role": "doctor",
       "source": "하루에 두 번 식후에 이 약을 드세요.",
       "input": "Take this medicine twice a day after meals.",
       "vendor_result": {"meaning": 92, "final": 88}}'
    • 토큰을 켰으면 -H "Authorization: Bearer $JUDGE_API_TOKEN" 추가
    • 응답 읽는 법: POST /judge/faithfulness
