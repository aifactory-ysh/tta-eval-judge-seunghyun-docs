    GET /ping — 살아 있는지 확인¶

    무엇을 하나 · 언제 쓰나¶

    • 판정 서버가 켜져 있는지, 어떤 모델 이름으로 떠 있는지, 지금까지의 호출 통계를 돌려줌
    • 판정 모델을 부르지 않음 — 사용 한도를 쓰지 않음
    • 쓰는 때
      • 서버를 켠 직후(make judge-up이 3초 뒤 자동으로 부름, Makefile:19)
      • 실행기 run_judge.py가 판정을 시작하기 전에 1번. ok가 참이 아니면 멈춤 (src/judge_api/run_judge.py:219-221)
      • 긴 판정 도중 진행 · 오류 수를 볼 때

    경로 · 메서드¶

    • GET /ping (src/judge_api/app.py:333-335)
    • 요청 본문 · 쿼리 없음

    요청 필드¶

    • 없음

    응답 필드¶

    필드 형 뜻 가능한 값
    ok 불 서버가 응답함 항상 true
    ts 문자열 서버 시각(UTC, ISO 8601, 밀리초까지) 예: 2026-11-16T05:00:00.000+00:00
    judge_model 문자열 주 판정 모델 이름(JUDGE_MODEL) —
    xling_model 문자열 교차 확인 모델 이름(JUDGE_MODEL_XLING) —
    stats 객체 서버가 켜진 뒤 성공한 판정 수와 오류 수(아래 표) —
    shannon 객체 또는 null 주 판정 모델 API 호출 통계(아래 표). 서버 시작 처리 전이면 null —
    concurrency_limit 정수 또는 null 주 판정 모델 API에 지금 허용한 동시 호출 수(자동 조절 값). 시작 처리 전이면 null 처음 4
    • stats 안 (src/judge_api/app.py:41, :261, :284, :298, :310-313)
    키 뜻
    faithfulness · rubric · meta · robustness 엔드포인트별로 판정 모델 결과를 받아 응답을 만든 횟수
    model_errors 판정 모델 호출 실패 횟수(502를 돌려준 원인)
    xling_mode JUDGE_XLING 값(on · off · auto)
    xling_skipped 교차 확인을 건너뛴 횟수(최근 실패 뒤 대기 중이라서)
    xling_circuit_open 지금 교차 확인을 건너뛰는 중인지
    xling_errors 교차 확인 모델 실패 횟수 — 처음 실패한 뒤에만 나타남
    • shannon 안 (src/common/core.py:159, :187-188)
    키 뜻
    calls 판정 모델 API에 보낸 시도 수(다시 시도 포함)
    ok 2xx로 끝난 요청 수
    retries 다시 시도한 수
    fail 끝내 실패한 요청 수
    status 상태 코드별 횟수(예: {"200": 10, "429": 2}, 연결 실패는 "None")

    예시¶

    curl -s http://127.0.0.1:8787/ping

    import asyncio, sys
sys.path.insert(0, "src")            # 저장소 최상위에서 실행
from judge_api.client import JudgeClient

async def main():
    c = JudgeClient()                # 기본 주소: JUDGE_API_URL 또는 http://127.0.0.1:8787
    print(await c.ping())
    await c.aclose()

asyncio.run(main())

    응답 예시¶

    • 예시(실제 호출 결과 아님) — 서버를 켠 뒤 판정을 몇 번 한 상태를 코드의 응답 구조대로 손으로 씀
    {
  "ok": true,
  "ts": "2026-11-16T05:00:00.000+00:00",
  "judge_model": "<JUDGE_MODEL 값>",
  "xling_model": "<JUDGE_MODEL_XLING 값>",
  "stats": {
    "faithfulness": 12, "rubric": 0, "meta": 3, "robustness": 0, "model_errors": 0,
    "xling_mode": "auto", "xling_skipped": 0, "xling_circuit_open": false
  },
  "shannon": {"calls": 16, "ok": 15, "retries": 1, "fail": 0, "status": {"200": 15, "429": 1}},
  "concurrency_limit": 4
}

    판정 값 읽는 법¶

    • 판정 값 없음. ok가 true면 켜진 것
    • 판정이 자꾸 502로 끝날 때: stats.model_errors · shannon.status의 429 · 5xx 횟수를 볼 것

    주의할 점¶

    • JudgeClient.ping()은 실패해도 예외를 내지 않고 {"error": ...}를 돌려줌 → ok 키로 확인할 것 (src/judge_api/client.py:38-40)
    • shannon · concurrency_limit가 null이면 서버 시작 처리(startup)가 돌지 않은 것 — uvicorn으로 띄운 서버에서는 값이 있음. FastAPI TestClient를 with 없이 쓰면 null로 나옴
    • stats는 서버를 끄면 사라짐(메모리에만 있음)
    • 응답에 모델 이름이 들어 있음 → 결과를 밖으로 공유할 때 주의
