    기업별 판정 기준¶

    이 쪽에서 알 수 있는 것

    • 평가 항목(무엇을 시험하는지의 묶음)마다 실패 · 통과가 되는 조건
    • 각 조건을 규칙이 정하는지, 판정 모델이 정하는지
    • 문턱 값(점수 기준)과 그 값이 있는 코드 위치

    읽는 법¶

    • 실패 · 통과는 서비스 쪽 표기(용어 풀이). 조건에 들지 않으면 검토필요
    • "정하는 쪽"
      • 규칙: 규칙 판정만으로 확정
      • 규칙→모델: 규칙이 먼저 정하고, 판정 모델 결과가 있으면 판정 집계에서 판정 모델 결과로 정함
    • 펀웨이브 점수: final = 기업이 준 최종 점수, meaning = 기업이 준 의미 점수(0~100)
    • 판정 모델 쪽 값의 뜻: 엔드포인트 사용법의 각 쪽

    • 근거충실성이 검토필요로 남는 경우
      • 언어 불일치 표시가 붙음 (src/report/rules/funwave.py:149-150)
      • 오류 통역문이 입력 필터에 막혀 채점되지 않음 (src/report/rules/funwave.py:151-154, src/report/verdict/funwave.py:158-160)
    • 근거충실성 판정 집계 순서(판정 모델 결과가 있을 때)
      1. 오류 통역문이 필터에 막힘 → 검토필요
      2. 정확한 통역: 과소 채점이면 실패 → 충실도 60 미만이면 검토필요 → 나머지 통과
      3. 오류 통역: 규칙이 통과(기대 범위 안)면 통과 → 과대 채점이면 실패 → 차이 15점 이내면 통과 → 나머지 검토필요
    • 기업 점수 평가: 기업 meaning − 판정 모델 충실도의 절댓값 15 이하 적정, 양수 과대, 음수 과소 (src/judge_api/app.py:159-167)
    • 불일치 원인 분류(/judge/meta)는 사유 문장에만 붙고 판정 값은 바꾸지 않음
