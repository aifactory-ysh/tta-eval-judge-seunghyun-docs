    기업별 판정 기준¶

    • 표의 "실패 / 통과"는 서비스 쪽 표기(처음 화면의 대응표). 적힌 조건에 들지 않으면 검토필요
    • 모델 쪽 조건이 어느 엔드포인트의 어느 값인지: 엔드포인트 사용법의 각 쪽 "판정 값 읽는 법"
    • "정하는 쪽": 규칙 = rules.py만으로 확정 · 모델 = 독립 판정 모델 결과로 정함 · 규칙→모델 = 규칙이 먼저 정하고, 모델 결과가 있으면 판정 집계에서 모델 결과로 바뀜
    • 점수: final = 기업이 준 최종 점수, meaning = 기업이 준 의미 점수(펀웨이브 API 응답 값)
