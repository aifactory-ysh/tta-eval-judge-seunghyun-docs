    단계 사이의 관계¶

    • 규칙 판정과 독립 판정 모델은 서로 기다리지 않음 — 둘 다 기업 응답 파일을 읽음
    • 판정 집계가 두 결과를 (case_id, run)으로 맞춰 합침 (src/report/verdict.py:508-519)

    "모델 결과로 정함"의 뜻¶

    • 액티부키: 모델이 낸 판정 값을 그대로 씀. 규칙이 이미 실패 · 통과로 정한 행도 모델 결과가 있으면 모델 결과가 이김 (src/report/verdict.py:400, :410, :420, :431, :442, :472)
    • 펀웨이브(근거충실성만): 모델 충실도 · 기업 점수 평가와 규칙 결과를 정해진 순서로 합침 (src/report/verdict.py:312-344) — 순서는 /judge/faithfulness의 판정 값 읽는 법

    판정 흔들림¶

    • 문항을 2회 이상 판정한 경우, 회차마다 최종 판정을 다시 계산해 서로 다르면 judge_flip을 참으로 둠 — 판정 자체는 1회차 기준 (src/report/verdict.py:520-528, 1회차 선택 :77-78)
    • 회차별 판정은 judge_verdicts_by_call 열에 /로 이어 적음 (src/report/verdict.py:528)

    이 저장소 밖¶

    • 정제 단계의 제외 · 판정 대기 분류는 이 저장소 코드로 확인할 수 없음 — 원 작업 폴더의 정제본 생성 코드에 있음(한계와 빠진 것)
